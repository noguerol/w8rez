Everything runs locally

Images, SVG, PDF, EPS and video are converted in your browser. Nothing is uploaded; the local server binary (Ghostscript/ffmpeg) is only used for EPS, PDF and non-native video.

Shortcuts

  • Enter / Space on the drop zone → choose a file
  • Ctrl+C on the toolbar → copy the current output
  • Drag a file anywhere over the drop zone
